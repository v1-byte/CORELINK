# CORELINK Remote — alur di navbar REMOTE

## Prinsip
Support perbaikan HP / medsos **atas izin 2 pihak**. Bukan remote diam-diam.

## Alur yang dipakai
1. **ADMIN** (tab REMOTE) → **Share link APK User** (CoreLink Assist)
2. **USER** install APK dari link
3. **USER** Generate **Token** → kirim ke admin
4. **ADMIN** tempel token → minta sesi
5. **USER** setuju popup izin → sesi support
6. **USER atau ADMIN** bisa **STOP** kapan saja

## Nama
| Peran | Nama |
|--------|------|
| Admin | CoreLink Desk (di app CORELINK · tab REMOTE) |
| User | CoreLink Assist (APK di-share) |
